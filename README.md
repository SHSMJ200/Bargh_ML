# راهنمای استفاده از `app.py`

## نصب کتابخانه‌ها

برای اجرای برنامه، نیاز است کتابخانه‌های مورد نیاز نصب شوند. همه کتابخانه‌ها در فایل **`requirements.txt`** آمده‌اند.

### ۱. نصب در محیط مجازی (توصیه شده)

```bash
# ساخت محیط مجازی
python -m venv env

# فعال کردن محیط مجازی
# لینوکس / مک:
source env/bin/activate
# ویندوز:
env\Scripts\activate

# نصب کتابخانه‌ها
pip install -r requirements.txt
```

## مقدمه

برای استفاده از مدل‌های آموزش دیده، کافی است فایل **`app.py`** را اجرا کنید.
این برنامه:

* فایل اکسل داده‌های ورودی را می‌خواند.
* پیش‌بینی‌ها را محاسبه می‌کند.
* نتایج را در یک فایل اکسل خروجی ذخیره می‌کند.

> مسیر فایل‌های ورودی و خروجی در **`configs/prediction.yaml`** مشخص می‌شود و باید قبل از اجرا تعیین شود.

---

## تنظیمات کانفیگ (`prediction.yaml`)

### ۱. نوع داده‌ها

* اگر داده‌ها شامل ستون `temperature` باشند، برنامه از همان داده‌ها استفاده می‌کند.
* اگر ستون `temperature` موجود نباشد، برنامه به‌صورت خودکار داده‌های هواشناسی را **کراول** می‌کند.

### ۲. فرمت تاریخ

* داده‌ها می‌توانند به صورت **شمسی (Jalali)** یا **میلادی (Gregorian)** باشند.
* اگر داده‌ها فاقد ستون temperature هستند و برنامه قصد دارد داده‌های هواشناسی را کراول کند، تاریخ وارد شده باید متعلق به فردای روز اجرای برنامه باشد.
* نوع تاریخ باید در کانفیگ مشخص شود:

```yaml
is_jalali: true  # برای تاریخ شمسی
is_jalali: false # برای تاریخ میلادی
```

## الزامات فایل اکسل ورودی

### ستون‌های ضروری

`id`, `name`, `code`, `date`, `hour`

### توضیحات ستون‌ها

* `id`, `code`, `date`, `hour`: **مقادیر باید دقیق باشند**.
* `name`: مقدار دقیق خیلی مهم نیست، اما بهتر است تقریباً صحیح باشد.

### فرمت تاریخ

* باید به شکل **yyyy/mm/dd** باشد.
* فرمت برای تاریخ‌های شمسی یا میلادی یکسان است.

---

## نکات مهم

* مسیر فایل‌های ورودی و خروجی **حتماً** باید در `prediction.yaml` مشخص شوند.
* برنامه به صورت خودکار بررسی می‌کند که داده‌ها شامل ستون دما هستند یا خیر.
* پیش‌بینی‌ها در **فایل خروجی اکسل** ثبت می‌شوند و اطلاعات هر واحد تولید در همان فایل ذخیره خواهد شد.
* **تغییر در متغیر `power_units` در فایل `prediction.yaml` انجام نشود مگر به صورت آگاهانه**، زیرا این متغیر آی‌دی‌ها و نام نیروگاه‌ها را به هم مرتبط می‌کند.
* **برای آموزش مجدد مدل یا اعمال تغییرات در مراحل پاک‌سازی، تجمیع، فیلتر کردن و آموزش مدل، نیاز به آشنایی با کد است**، بنابراین توضیحات آن در این فایل داده نمی‌شود.

## نمونه فایل `prediction.yaml`

```yaml
# مسیر فایل اکسل ورودی
xlsx_input_path: "data/input.xlsx"

# مسیر فایل اکسل خروجی
xlsx_output_path: "data/output.xlsx"

# تعیین اینکه داده‌ها شامل ستون دما هستند یا نه
has_temperature_column: false

# تعیین فرمت تاریخ: "jalali" یا "gregorian"
is_jalali: true

# نگاشت id به نام واحدهای تولید نیروگاه
```
